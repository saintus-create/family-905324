# California Family Code

The California Family Code provides the statutory foundation for family-law research. Use this section to identify the relevant division, part, chapter, article, and section before reviewing current official text and related authority.

## Research guidance

Confirm every statutory citation against the California Legislative Information website. Pay particular attention to effective dates, amendments, cross-references, and statutory definitions.
