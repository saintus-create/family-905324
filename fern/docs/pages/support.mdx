This site is organized as a legal reference tool. Use it to locate the governing statute, understand its place in the code, and follow the surrounding legal structure.

## Use this reference

- Start with the Family Code overview to understand the system of divisions and parts.
- Move to the relevant division to see how the code is organized.
- Read the governing section in context, then follow the related provisions and definitions.

## Good research questions

- What section governs this issue?
- Where does this rule sit in the Family Code hierarchy?
- Which definitions or general provisions apply?
- What neighboring sections should I read next?

## Reference sources

- California Legislative Information
- Official statute text and citations
- Family Code sections and related materials

This should be treated as a practical navigation and research layer, not a replacement for the enacted legal text.
