# ELEC § 14435

**Hierarchy:** Division: 14. ELECTION DAY PROCEDURES > Chapter: 4. Closing of the Polls > Article: 3. Return of Supplies to the Clerk

**Citation:** ELEC § 14435

---

## Text

No list, tally, paper, or certificate returned from any election shall be set aside or rejected for want of form, nor because it is not strictly in accordance with this code, if it can be satisfactorily understood.

## Legislative History

(History: Added by Stats. 1998, Ch. 1073, Sec. 19. Effective January 1, 1999.)
