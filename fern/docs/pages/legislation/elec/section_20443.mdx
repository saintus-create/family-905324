# ELEC § 20443

**Hierarchy:** Division: 20. ELECTION CAMPAIGNS > Chapter: 5. Fair Campaign Practices > Article: 3. Code of Fair Campaign Practices

**Citation:** ELEC § 20443

---

## Text

Every code subscribed to by a candidate for public office pursuant to this chapter is a public record open for public inspection.

## Legislative History

(History: Enacted by Stats. 1994, Ch. 920, Sec. 2.)
