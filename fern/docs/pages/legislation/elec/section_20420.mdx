# ELEC § 20420

**Hierarchy:** Division: 20. ELECTION CAMPAIGNS > Chapter: 5. Fair Campaign Practices > Article: 2. Definitions

## Text

As used in this chapter, “Code” means the Code of Fair Campaign Practices.
