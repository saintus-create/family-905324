# FAC § 11765

**Hierarchy:** Division: 6. PEST CONTROL OPERATIONS > Chapter: 4. Pest Control > Article: 3. Report of Damage From Pesticides

**Citation:** FAC § 11765

---

## Text

The failure to file a verified report of loss is evidence that no loss, nonperformance, or damage occurred.

(History: Amended by Stats. 1974, Ch. 774.)
