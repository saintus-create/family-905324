# FAC § 11731

**Hierarchy:** Division: 6. PEST CONTROL OPERATIONS > Chapter: 4. Pest Control > Article: 2. Registration

**Citation:** FAC § 11731

---

## Text

“Commissioner,” as used in this article, includes the director in any county in which there is no commissioner.

## Legislative History

(History: Enacted by Stats. 1967, Ch. 15.)
