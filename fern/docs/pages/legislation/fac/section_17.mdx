# FAC § 17

**Citation:** FAC § 17

---

## Text

If any provision of this code or its application to any person or circumstance is held invalid, the remainder of the code or the application of the provision to any other person or circumstance is not affected.

(History: Enacted by Stats. 1967, Ch. 15.)
