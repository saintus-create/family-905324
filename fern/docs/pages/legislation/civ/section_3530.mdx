# CIV § 3530

**Hierarchy:** Part: 4. MAXIMS OF JURISPRUDENCE > Title: 4. MOTION PICTURES

**Citation:** CIV § 3530

---

## Text

That which does not appear to exist is to be regarded as if it did not exist.

## Legislative History

(History: Enacted 1872.)
