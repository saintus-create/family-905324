# CIV § 1171

**Hierarchy:** Title: 4. TRANSFER > Chapter: 4. Recording Transfers > Article: 2. Mode of Recording

**Citation:** CIV § 1171

---

## Text

Grants, absolute in terms, are to be recorded in one set of books, and mortgages in another.

## Legislative History

(History: Enacted 1872.)
