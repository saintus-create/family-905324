# CIV § 1681

**Hierarchy:** Title: 4.5. LIQUIDATED DAMAGES > Chapter: 2. Default on Real Property Purchase Contract

**Citation:** CIV § 1681

## Text

This chapter does not apply to real property sales contracts as defined in Section 2985.
