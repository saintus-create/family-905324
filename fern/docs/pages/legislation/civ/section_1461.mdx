# CIV § 1461

**Hierarchy:** Title: 3. TRANSFER OF OBLIGATIONS

**Citation:** CIV § 1461

---

## Text

The only covenants which run with the land are those specified in this Title, and those which are incidental thereto.

## Legislative History

(History: Enacted 1872.)
