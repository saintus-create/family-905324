# FGC § 11009

**Hierarchy:** Division: 8. DISTRICTS > Chapter: 1. Boundaries

**Citation:** FGC § 11009

---

## Text

The following constitutes Fish and Game District 312:

Those portions of the following counties not included in other districts: San Luis Obispo, Santa Barbara, Ventura, and Kern.

Except as otherwise provided all of the provisions of this code applicable to District 3 apply to District 312.
