# FGC § 11006

**Hierarchy:** Division: 8. DISTRICTS > Chapter: 1. Boundaries

**Citation:** FGC § 11006

---

## Text

The following constitutes Fish and Game District 214:

Lake County and the waters of Clear Lake.

Any reference in this code to Clear Lake refers to District 214.

Except as otherwise provided, all of the provisions of this code relating to District 2 apply to District 214.
