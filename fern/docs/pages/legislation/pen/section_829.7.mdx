# PEN § 829.7

**Hierarchy:** Title: 3. ADDITIONAL PROVISIONS REGARDING CRIMINAL PROCEDURE > Chapter: 4.2. Code Enforcement Officers

**Citation:** PEN § 829.7

---

## Text

Each local jurisdiction that employs code enforcement officers shall develop code enforcement officer safety standards appropriate for the code enforcement officers employed in their jurisdiction.

## Legislative History

(History: Added by Stats. 2021, Ch. 637, Sec. 2. (SB 296) Effective January 1, 2022.)
