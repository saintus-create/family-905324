# PEN § 852.4

**Hierarchy:** Title: 3. ADDITIONAL PROVISIONS REGARDING CRIMINAL PROCEDURE > Chapter: 5A. Uniform Act on Fresh Pursuit

**Citation:** PEN § 852.4

---

## Text

Section 852.2 of this code shall not be construed so as to make unlawful any arrest in this State which would otherwise be lawful.

## Legislative History

(History: Added by Stats. 1937, Ch. 301.)
