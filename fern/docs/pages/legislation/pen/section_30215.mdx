# PEN § 30215

**Hierarchy:** Title: 4. FIREARMS > Chapter: 1. Ammunition > Article: 1. Flechette Dart Ammunition or Bullet Containing or Carrying an Explosive Agent

## Text

Section 30210 does not apply to tracer ammunition manufactured for use in a shotgun.
