# PEN § 999

**Hierarchy:** Title: 6. PLEADINGS AND PROCEEDINGS BEFORE TRIAL > Chapter: 2. Setting Aside the Indictment or Information

**Citation:** PEN § 999

---

## Text

An order to set aside an indictment or information, as provided in this chapter, is no bar to a future prosecution for the same offense.
