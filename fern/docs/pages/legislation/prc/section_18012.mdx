# PRC § 18012

**Hierarchy:** Division: 12.7. PLASTIC WASTE > Chapter: 2. Containers and Packaging

**Citation:** PRC § 18012

---

## Text

“Label” means a code label described in Section 18015 molded into the bottom of the plastic product.

(History: Added by Stats. 1988, Ch. 838, Sec. 1.)
