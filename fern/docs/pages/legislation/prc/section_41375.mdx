# PRC § 41375

**Hierarchy:** Division: 30. WASTE MANAGEMENT > Chapter: 3. County Source Reduction and Recycling Elements > Article: 4. Recycling Component

**Citation:** PRC § 41375

---

## Text

The county recycling component shall evaluate industrial, commercial, residential, governmental, and other curbside, mobile, dropoff, and buy-back recycling programs, manual and automated material recovery facilities, zoning, and building code changes which encourage recycling of materials, and rate structures which encourage recycling of materials.

## Legislative History

(History: Added by Stats. 1989, Ch. 1095, Sec. 22.)
