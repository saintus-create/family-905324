# PRC § 42413

**Hierarchy:** Division: 30. WASTE MANAGEMENT > Chapter: 7. Retreaded Tire Program > Article: 2. Retreaded Tire Program

## Text

Emergency vehicles, as defined in Section 165 of the California Vehicle Code are exempt from this provision.
