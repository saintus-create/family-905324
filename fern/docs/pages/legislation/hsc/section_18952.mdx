# HSC § 18952

**Hierarchy:** Division: 13. HOUSING > Part: 2.7. STATE HISTORICAL BUILDING CODE

**Citation:** HSC § 18952

---

## Text

This part shall apply to all qualified historical buildings or structures as defined in Section 18955.

(History: Amended by Stats. 2003, Ch. 504, Sec. 2. Effective January 1, 2004.)
