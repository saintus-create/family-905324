# HSC § 18940

**Hierarchy:** Division: 13. HOUSING > Part: 2.5. STATE BUILDING STANDARDS > Chapter: 4. The California Building Standards Code

**Citation:** HSC § 18940

---

## Text

Codification of building standards approved by the commission shall be incorporated into the code and shall not be incorporated into other individual titles of state agencies in the California Code of Regulations.

## Legislative History

(History: Amended by Stats. 1992, Ch. 897, Sec. 31. Effective January 1, 1993.)
