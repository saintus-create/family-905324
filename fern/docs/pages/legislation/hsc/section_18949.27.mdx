# HSC § 18949.27

**Hierarchy:** Division: 13. HOUSING > Part: 2.5. STATE BUILDING STANDARDS > Chapter: 7. Construction Inspectors, Plans Examiners, and Building Officials

**Citation:** HSC § 18949.27

---

## Text

For purposes of this chapter, “building official” means the individual invested with the responsibility for overseeing local code enforcement activities, including administration of the building department, interpretation of code requirements, and direction of the code adoption process.

## Legislative History

(History: Added by renumbering Section 18967 by Stats. 1996, Ch. 124, Sec. 62. Effective January 1, 1997.)
