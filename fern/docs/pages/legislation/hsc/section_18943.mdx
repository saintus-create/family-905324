# HSC § 18943

**Hierarchy:** Division: 13. HOUSING > Part: 2.5. STATE BUILDING STANDARDS > Chapter: 4. The California Building Standards Code

**Citation:** HSC § 18943

---

## Text

Building standards in individual titles of the California Code of Regulations other than the California Building Standards Code shall have no force or effect after January 1, 1985.

## Legislative History

(History: Amended by Stats. 2003, Ch. 62, Sec. 184. Effective January 1, 2004.)
