# HSC § 18944.7

**Hierarchy:** Division: 13. HOUSING > Part: 2.5. STATE BUILDING STANDARDS > Chapter: 4. The California Building Standards Code

**Citation:** HSC § 18944.7

---

## Text

The alternative building regulations and building standards authorized under the State Historical Building Code (Part 2.7 (commencing with Section 18950) of Division 13) which have been published in Part 8 of the California Building Standards Code shall be maintained as a separate and distinct part or portion of the California Building Standards Code pursuant to that title.

(History: Amended by Stats. 1988, Ch. 1194, Sec. 30.)
