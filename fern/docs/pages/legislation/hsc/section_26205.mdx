# HSC § 26205

**Hierarchy:** Division: 20. MISCELLANEOUS HEALTH AND SAFETY PROVISIONS > Chapter: 20. Certified Code Enforcement Officers

## Text

This chapter shall be known, and may be cited, as the Code Enforcement Officer Standards Act.

(History: Added by Stats. 2016, Ch. 246, Sec. 2. (AB 2228) Effective January 1, 2017.)
