# HSC § 18944.5

**Hierarchy:** Division: 13. HOUSING > Part: 2.5. STATE BUILDING STANDARDS > Chapter: 4. The California Building Standards Code

**Citation:** HSC § 18944.5

---

## Text

The code shall be binding on the state and other public agencies, including federal agencies to the extent permitted by federal law, in the same manner as it binds private parties or entities.

## Legislative History

(History: Added by Stats. 1979, Ch. 1152.)
