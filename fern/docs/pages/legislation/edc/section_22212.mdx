# EDC § 22212

**Hierarchy:** Division: 1. GENERAL EDUCATION CODE PROVISIONS > Part: 13. STATE TEACHERS' RETIREMENT SYSTEM > Title: 1. GENERAL EDUCATION CODE PROVISIONS > Chapter: 3. Retirement Board

## Text

The board shall appoint such employees as are necessary to administer the plan and the system.

(History: Amended by Stats. 1998, Ch. 965, Sec. 21. Effective January 1, 1999.)
