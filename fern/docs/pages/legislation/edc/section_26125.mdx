# EDC § 26125

**Hierarchy:** Division: 1. GENERAL EDUCATION CODE PROVISIONS > Part: 14. STATE TEACHERS’ RETIREMENT SYSTEM CASH BENEFIT PROGRAM > Title: 1. GENERAL EDUCATION CODE PROVISIONS > Chapter: 2. Definitions

**Citation:** EDC § 26125

---

## Text

“Employer contribution” means the amount contributed by the employer to the Cash Balance Benefit Program with respect to the participant.

## Legislative History

(History: Amended by Stats. 1998, Ch. 965, Sec. 239. Effective January 1, 1999.)
