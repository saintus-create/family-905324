# EDC § 18746

**Hierarchy:** Division: 1. GENERAL EDUCATION CODE PROVISIONS > Part: 11. LIBRARIES > Title: 1. GENERAL EDUCATION CODE PROVISIONS > Chapter: 4. California Library Services Act > Article: 5. Library System Services

**Citation:** EDC § 18746

---

## Text

Each system shall annually apply to the state board for funds for planning, coordination, and evaluation of the overall systemwide services authorized by this chapter.

(History: Amended by Stats. 1987, Ch. 1452, Sec. 107.)
