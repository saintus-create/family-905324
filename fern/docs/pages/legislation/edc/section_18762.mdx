# EDC § 18762

**Hierarchy:** Division: 1. GENERAL EDUCATION CODE PROVISIONS > Part: 11. LIBRARIES > Title: 1. GENERAL EDUCATION CODE PROVISIONS > Chapter: 4. California Library Services Act > Article: 6. Statewide Services

**Citation:** EDC § 18762

---

## Text

Each reference center established pursuant to Section 18760 may enter into reciprocal or contractual agreements with libraries or any other information source for the purpose of making available their materials and informational services for the benefit of the library users of this state. Each California public library participating in any program under this chapter shall make materials and services available, as needed, to state reference centers.

(History: Added by Stats. 1977, Ch. 1255.)
