# EDC § 22122.5

**Hierarchy:** Division: 1. GENERAL EDUCATION CODE PROVISIONS > Part: 13. STATE TEACHERS' RETIREMENT SYSTEM > Title: 1. GENERAL EDUCATION CODE PROVISIONS > Chapter: 2. Definitions

**Citation:** EDC § 22122.5

---

## Text

“Defined Benefit Program” means the Defined Benefit Program provided in the State Teachers’ Retirement Plan as set forth in this part.

(History: Amended by Stats. 1998, Ch. 1048, Sec. 3. Effective January 1, 1999.)
