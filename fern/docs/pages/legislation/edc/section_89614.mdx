# EDC § 89614

**Hierarchy:** Division: 8. CALIFORNIA STATE UNIVERSITY > Part: 55. CALIFORNIA STATE UNIVERSITY > Title: 3. POSTSECONDARY EDUCATION > Chapter: 5.5. Optional Retirement Program > Article: 2. Definitions

## Text

“Participant” means any person electing the optional retirement program.
