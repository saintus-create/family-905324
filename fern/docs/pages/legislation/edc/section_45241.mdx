# EDC § 45241

**Hierarchy:** Division: 3. LOCAL ADMINISTRATION > Part: 25. EMPLOYEES > Title: 2. ELEMENTARY AND SECONDARY EDUCATION > Chapter: 5. Classified Employees > Article: 6. Merit System

**Citation:** EDC § 45241

---

## Text

In any district in which the procedure set forth in this article has been incorporated the governing board shall employ, pay, and otherwise control the services of persons in positions not requiring certification qualifications only in accordance with the provisions of this article.

No governing board shall remove a position from the classified service by title assignment or otherwise which would then require an incumbent to be credentialed if such position is not required by this code to be designated as certificated.
