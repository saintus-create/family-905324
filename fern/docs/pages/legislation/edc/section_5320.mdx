# EDC § 5320

**Hierarchy:** Division: 1. GENERAL EDUCATION CODE PROVISIONS > Part: 4. ELECTIONS > Title: 1. GENERAL EDUCATION CODE PROVISIONS > Chapter: 3. Conduct of Elections > Article: 2. Order and Call of Elections

**Citation:** EDC § 5320

---

## Text

The act authorized by this code of any officer, board, county committee, group of electors, or any other persons or agencies which commences an election proceeding, and any mandatory provision of this code requiring that an election be held, is an “order of election.”

## Legislative History

(History: Enacted by Stats. 1976, Ch. 1010.)
