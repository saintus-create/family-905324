# EDC § 27101

**Hierarchy:** Division: 1. GENERAL EDUCATION CODE PROVISIONS > Part: 14. STATE TEACHERS’ RETIREMENT SYSTEM CASH BENEFIT PROGRAM > Title: 1. GENERAL EDUCATION CODE PROVISIONS > Chapter: 12. Beneficiary

**Citation:** EDC § 27101

---

## Text

In the event the participant dies without a valid beneficiary designation on file with the system, any lump-sum death benefit under this part shall be payable to the estate of the participant.

## Legislative History

(History: Amended by Stats. 1998, Ch. 965, Sec. 296. Effective January 1, 1999.)
