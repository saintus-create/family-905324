# EDC § 26124

**Hierarchy:** Division: 1. GENERAL EDUCATION CODE PROVISIONS > Part: 14. STATE TEACHERS’ RETIREMENT SYSTEM CASH BENEFIT PROGRAM > Title: 1. GENERAL EDUCATION CODE PROVISIONS > Chapter: 2. Definitions

**Citation:** EDC § 26124

---

## Text

“Employer contribution rate” means the percentage of salary that determines the amount the employer contributes to the Cash Balance Benefit Program with respect to each employee who is a participant.

## Legislative History

(History: Amended by Stats. 1998, Ch. 965, Sec. 238. Effective January 1, 1999.)
