# EDC § 25000

**Hierarchy:** Division: 1. GENERAL EDUCATION CODE PROVISIONS > Part: 13. STATE TEACHERS' RETIREMENT SYSTEM > Title: 1. GENERAL EDUCATION CODE PROVISIONS > Chapter: 38. Defined Benefit Supplement Program > Article: 1. General Provisions

**Citation:** EDC § 25000

---

## Text

The Defined Benefit Supplement Program is hereby established to provide supplemental benefits for members of the Defined Benefit Program. The Teachers’ Retirement Board shall administer the Defined Benefit Supplement Program in accordance with the provisions of this part.

## Legislative History

(History: Amended (as added by Stats. 2000, Ch. 74) by Stats. 2000, Ch. 1021, Sec. 45. Effective January 1, 2001.)
