# EDC § 22110.1

**Hierarchy:** Division: 1. GENERAL EDUCATION CODE PROVISIONS > Part: 13. STATE TEACHERS' RETIREMENT SYSTEM > Title: 1. GENERAL EDUCATION CODE PROVISIONS > Chapter: 2. Definitions

**Citation:** EDC § 22110.1

---

## Text

“Cash Balance Benefit Program” means the benefit program of the State Teachers’ Retirement Plan as set forth in Part 14 (commencing with Section 26000).

## Legislative History

(History: Amended by Stats. 1998, Ch. 1048, Sec. 2. Effective January 1, 1999.)
