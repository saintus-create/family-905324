# RTC § 8753

**Hierarchy:** Division: 2. OTHER TAXES > Part: 3. USE FUEL TAX > Chapter: 4. Determinations > Article: 1. Returns and Payments

**Citation:** RTC § 8753

---

## Text

The user shall accompany each return with a remittance payable to the board for the amount of tax due.
