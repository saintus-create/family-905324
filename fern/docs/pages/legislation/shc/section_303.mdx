# SHC § 303

**Hierarchy:** Division: 1. STATE HIGHWAYS > Chapter: 2. The State Highway System > Article: 3. The State Highway Routes

**Citation:** SHC § 303

---

## Text

Route 3 is from:

(a) Route 36 near Peanut to Route 299 near Douglas City.

(b) Route 299 near Weaverville to Montague via Main Street in Yreka.
