# SHC § 306

**Hierarchy:** Division: 1. STATE HIGHWAYS > Chapter: 2. The State Highway System > Article: 3. The State Highway Routes

**Citation:** SHC § 306

## Text

Route 6 is from Route 395 near Bishop to the Nevada state line near Montgomery Pass.
