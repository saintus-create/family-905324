# SHC § 479

**Hierarchy:** Division: 1. STATE HIGHWAYS > Chapter: 2. The State Highway System > Article: 3. The State Highway Routes

**Citation:** SHC § 479

## Text

Route 179 is from Route 80 near Vacaville to Route 128 near Berryessa Reservoir.
