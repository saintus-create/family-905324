# SHC § 427

**Hierarchy:** Division: 1. STATE HIGHWAYS > Chapter: 2. The State Highway System > Article: 3. The State Highway Routes

**Citation:** SHC § 427

---

## Text

Route 127 is from Route 15 near Baker to the Nevada state line via the vicinity of Death Valley Junction.
