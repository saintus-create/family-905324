# SHC § 350

**Hierarchy:** Division: 1. STATE HIGHWAYS > Chapter: 2. The State Highway System > Article: 3. The State Highway Routes

**Citation:** SHC § 350

---

## Text

Route 50 is from Route 80 west of Sacramento to the Nevada state line near Lake Tahoe via Placerville.
