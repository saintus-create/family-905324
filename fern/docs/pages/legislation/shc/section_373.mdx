# SHC § 373

**Hierarchy:** Division: 1. STATE HIGHWAYS > Chapter: 2. The State Highway System > Article: 3. The State Highway Routes

**Citation:** SHC § 373

---

## Text

Route 73 is from Route 5 near San Juan Capistrano to Route 405 via the San Joaquin Hills.

(History: Amended by Stats. 2003, Ch. 525, Sec. 21. Effective January 1, 2004.)
