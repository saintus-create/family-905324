# SHC § 566

**Hierarchy:** Division: 1. STATE HIGHWAYS > Chapter: 2. The State Highway System > Article: 3. The State Highway Routes

**Citation:** SHC § 566

---

## Text

Route 266 is from the Nevada state line easterly of Oasis to the Nevada state line northerly of Oasis.
