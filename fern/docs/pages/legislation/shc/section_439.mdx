# SHC § 439

**Hierarchy:** Division: 1. STATE HIGHWAYS > Chapter: 2. The State Highway System > Article: 3. The State Highway Routes

**Citation:** SHC § 439

---

## Text

Route 139 is from:

(a) Route 36 in Susanville to Route 299 near Adin.

(b) Route 299 near Canby to the Oregon state line near Hatfield.
