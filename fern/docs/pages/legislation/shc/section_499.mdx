# SHC § 499

**Hierarchy:** Division: 1. STATE HIGHWAYS > Chapter: 2. The State Highway System > Article: 3. The State Highway Routes

**Citation:** SHC § 499

---

## Text

Route 199 is from Route 101 near Crescent City to the Oregon state line via the Smith River.
