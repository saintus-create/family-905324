# SHC § 567

**Hierarchy:** Division: 1. STATE HIGHWAYS > Chapter: 2. The State Highway System > Article: 3. The State Highway Routes

**Citation:** SHC § 567

---

## Text

Route 267 is from Route 80 near Truckee to Route 28 near Kings Beach, Lake Tahoe via Northshore Boulevard.
