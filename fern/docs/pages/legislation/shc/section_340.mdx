# SHC § 340

**Hierarchy:** Division: 1. STATE HIGHWAYS > Chapter: 2. The State Highway System > Article: 3. The State Highway Routes

**Citation:** SHC § 340

---

## Text

Route 40 is from Route 15 at Barstow to the Arizona state line near Topock, Arizona via Needles.
