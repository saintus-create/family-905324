# SHC § 388

**Hierarchy:** Division: 1. STATE HIGHWAYS > Chapter: 2. The State Highway System > Article: 3. The State Highway Routes

**Citation:** SHC § 388

---

## Text

Route 88 is from:

(a) Route 99 near Stockton to Route 49 passing south of Ione.

(b) Route 49 in Jackson to the Nevada state line via Pine Grove, Silver Lake, and Kirkwood.
