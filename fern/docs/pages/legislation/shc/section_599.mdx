# SHC § 599

**Hierarchy:** Division: 1. STATE HIGHWAYS > Chapter: 2. The State Highway System > Article: 3. The State Highway Routes

**Citation:** SHC § 599

---

## Text

Route 299 is from:

(a) Route 101 near Arcata to Route 395 at Alturas.

(b) Route 395 near Alturas to the Nevada state line via Cedarville.
