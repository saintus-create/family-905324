# WAT § 9375

**Hierarchy:** Division: 5. FLOOD CONTROL > Chapter: 5. Bond Elections > Article: 3. Voting Lists and Ballots

**Citation:** WAT § 9375

---

## Text

The board shall, prior to the election, cause to be prepared and certified by its secretary or assistant secretary, and furnished to the board of election in each voting district, a true and correct voting list containing all of the following:

(a) The reference number of each tract separately assessed upon the assessment list.

(b) The name of the person to whom each tract assessed.

(c) The amount of the assessment on each tract with reference to which the election is to be held.

(History: Added by Stats. 1943, Ch. 369.)
