# WAT § 2046

**Hierarchy:** Division: 2. WATER > Chapter: 1. Reference by Courts of This State > Article: 3. Expenses of Reference

**Citation:** WAT § 2046

---

## Text

Any party failing to object to the expense of a reference or the apportionment thereof is conclusively deemed to have waived all objection thereto.

(History: Enacted by Stats. 1943, Ch. 368.)
