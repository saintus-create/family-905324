# WAT § 1324

**Hierarchy:** Division: 2. WATER > Chapter: 3. Notice of Application > Article: 3. Posting and Mailing Notice

**Citation:** WAT § 1324

---

## Text

The board may cancel any application for failure of the applicant to file proof of posting in accordance with this article, provided the board first gives the applicant written notice of such possible cancellation and 15 days in which to file proof of posting.

## Legislative History

(History: Added by Stats. 1963, Ch. 501.)
