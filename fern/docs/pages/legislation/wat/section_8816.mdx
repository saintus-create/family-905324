# WAT § 8816

**Hierarchy:** Division: 5. FLOOD CONTROL > Chapter: 5. Assessments > Article: 4. Assessment Lists

**Citation:** WAT § 8816

---

## Text

In the assessment list for any county the assessors may use any abbreviation in common use in that county, without explanation thereof.

## Legislative History

(History: Added by Stats. 1943, Ch. 369.)
