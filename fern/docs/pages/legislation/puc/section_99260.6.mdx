# PUC § 99260.6

**Hierarchy:** Division: 10. TRANSIT DISTRICTS > Part: 11. PROVISIONS APPLICABLE TO ALL PUBLIC TRANSIT > Chapter: 4. Transportation Development > Article: 4. Claims for Funds

## Text

Public agencies authorized to file claims pursuant to Section 99234.9 may file claims under this article.
