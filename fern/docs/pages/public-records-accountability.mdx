# Follow the public record.

A source-linked research collection for public funding, official reports, accountability actions, and case-status records. Every entry is designed to answer what happened, when, under which authority, and where the supporting record lives.

## Browse by Record Type

<Callout intent="info">
**Evidence before conclusions.** Use the collection to inspect public records, not to infer guilt from an allegation, filing, or arrest. Procedural status and source provenance are part of every accountable record.
</Callout>

## Corpus Profile (Version 1.0)

| Feature | Description |
| :--- | :--- |
| **Coverage** | California · local-first |
| **Primary sources** | Cal OES · POST · CJP · Treasury |
| **Record focus** | Funding · reports · final actions |
| **Evidence model** | Source link · date · hash · status |

Public records are preserved with their provenance. The interface does not create scores, labels, or conclusions beyond the cited official record.

## Read the Status

**Arrest, allegation, filing, settlement, discipline, and final disposition are not the same record.**

The index keeps those distinctions visible. It publishes the official source, date, status, and stated outcome instead of a score or reputation label.
