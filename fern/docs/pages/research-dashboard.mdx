## Verification states

**Verified** is reserved for records checked against an authoritative source.

**Indexed** identifies useful records awaiting primary verification.

**Unresolved** identifies material questions that should not be silently filled by inference.

**Analytical** identifies a relationship or proposition produced through research analysis rather than directly stated by a source.

## Research path

`QUESTION`

↓

`SOURCE DISCOVERY`

↓

`VERIFIED CORPUS`

↓

`RELATIONSHIP GRAPH`

↓

`ARGUMENT / EMPIRICAL ANALYSIS`

↓

`SOURCE-GROUNDED AI`

The AI layer is last because it depends on the first five. The system should become more useful as the underlying evidence becomes better, not more confident merely because a language model has been given more text.
