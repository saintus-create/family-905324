# Public Records Overview

This section tracks institutional data, financial allocations, and training records for law enforcement and related public safety entities in California. 

The goal is to map the flow of funding, track vendor relationships, and index the certification status of agencies and officers using primary public sources.

## Data Methodology

All data in this section is strictly derived from primary public sources, including:
- State and federal grant databases
- State controller and municipal budget transparency portals
- POST open data portals
- Publicly available vendor contracts and board minutes
- Court records and official municipal disclosures
