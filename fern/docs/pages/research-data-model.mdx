<Callout intent="info">
The site is being built as a connected research system. A statute, case, bill, person, institution, dataset, or argument should be able to point to the other records that give it meaning.
</Callout>

## Core records

<CardGroup cols={3}>
  <Card title="Authority" icon="fa-regular fa-scale-balanced">Statutes, regulations, rules, constitutional provisions, and official guidance.</Card>
  <Card title="Case" icon="fa-regular fa-gavel">Judicial decisions with court, date, posture, holdings, citations, dissents, and treatment.</Card>
  <Card title="Legislation" icon="fa-regular fa-file-lines">Bills, amendments, chapters, votes, history, and related measures.</Card>
  <Card title="Person" icon="fa-regular fa-user">Judges, attorneys, legislators, scholars, authors, and other publicly documented participants.</Card>
  <Card title="Institution" icon="fa-regular fa-building">Courts, universities, agencies, clinics, legal organizations, and research centers.</Card>
  <Card title="Evidence" icon="fa-regular fa-chart-line">Studies, statistics, datasets, reports, and other empirical sources.</Card>
</CardGroup>

## Relationships are data

The graph should preserve relationships such as:

`CASE → cites → CASE`

`CASE → interprets → AUTHORITY`

`BILL → amends → AUTHORITY`

`BILL → related-to → BILL`

`AUTHORITY → derived-from → LEGISLATION`

`PERSON → argued → CASE`

`PERSON → authored → PUBLICATION`

`INSTITUTION → hosts → RESEARCH`

`CASE → contains → DISSENT`

`ARGUMENT → attacks → ARGUMENT`

`CLAIM → supported-by → EVIDENCE`

## Provenance

Every important relationship should ultimately be traceable to a source. The interface should distinguish source fact, extracted fact, analyst interpretation, empirical result, and AI-generated proposition.

## Future graph interfaces

The same underlying records can power citation graphs, legislative timelines, case maps, procedural timelines, person/institution directories, topic maps, argument graphs, and AI retrieval.

The objective is simple: **one source of truth, many useful views.**
